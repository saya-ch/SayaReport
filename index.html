观察一：AI 岗位从"做 AI"走向"用 AI"

2024H1 核心算法岗占 AI 岗位 68%，到 2026H1 变为 45%； 同期 AI 应用岗 + 运营/销售/设计关联岗合计占比达 55%。 方向启示：Agent 开发 / AI 产品 / AI 运营是增长最快的三个方向。

信息来源：新华网 · 科锐国际

观察二：AI Agent 进入生产力验证与商业化放量早期阶段

企业通用 Agent 率先商业化落地，行业垂直 Agent 加速从试点走向规模化。 竞争重点从参数规模和模型性能转向任务完成能力、业务适配能力和单位任务成本。

信息来源：36 氪研究院 2026

观察三：国央企 AI 岗位增长 122%，增速超外资企业

国央企 AI 岗位中算法工程师占比 37.5%（各类企业最高）， 5 年以上经验人才需求占比更高。 方向启示：能源/电力/制造/交通领域的企业级 AI Agent 落地是下一个风口。 石大能源背景在此有天然优势。

信息来源：东方财富 · 科锐国际

观察四：AI 编程 Agent 成为主流生产力工具

Cursor → Devin Desktop → Claude Code 正从"AI IDE"变成"团队级 Agent 平台"。 Claude Code Dynamic Workflows 可自动创建并调度数十到数百个后台 Agent 并行工作。 个人能力启示：熟练使用至少一个 AI 编程 Agent 是 2026 年开发者的标配。

信息来源：LearnAgent 中文知识库
